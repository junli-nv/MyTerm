# MyTerm 3.2

## 简体中文

新增标签内上下/左右分屏、分隔线调整、已有会话移入与移为独立标签。默认快捷键为 ⌘⇧H / ⌘⇧V，可在终端行为设置中自定义。分屏保留独立会话、SFTP 和 Codex 授权；会话保存恢复支持分屏结构和选中区域，分隔比例不保存。历史入口保留在菜单和侧栏。

## English

Add top/bottom and left/right splits within tabs, adjustable dividers, moving existing sessions and detaching panes. Defaults are ⌘⇧H / ⌘⇧V, customizable in Terminal Behavior. Panes retain independent sessions, SFTP and Codex authorization. Saved sessions preserve layout and selection, but not divider proportions. History remains available in menus and the sidebar.
