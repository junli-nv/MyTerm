# MyTerm 3.4.4

## 简体中文

- 明确 MyTerm 集群分组与 Codex 原生项目的区别；默认入口改称默认分组。
- 新增元数据刷新和可恢复/未找到/无法验证状态；读取失败保留记录，名称更新不改变最近打开日期。
- 支持分组改名，保留目录、对话及 SSH 关联，默认分组改名后不会重复创建。
- 启动前展示继续的对话及当前 SSH 目标。

## English

- Distinguish MyTerm cluster groups from native Codex projects; label the default entry Default group.
- Add metadata refresh and available/not-found/unverified status. Failures preserve entries; title updates retain last-opened dates.
- Rename groups without changing directories, conversations or SSH associations; retain a renamed default group.
- Show the conversation and current SSH target before launch.
