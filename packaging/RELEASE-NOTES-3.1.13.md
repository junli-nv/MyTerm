# MyTerm 3.1.13

## 简体中文

SSH 配置新增可选目标服务器密码，留空保留已有密码；使用应用本地加密数据库，不写入会话配置。统一普通密码提示的凭据关联，保留旧记录迁移及密码拒绝后的更新流程。

## English

Add an optional destination password to SSH configuration. Blank retains the saved password; secrets use the local encrypted store and stay out of session configuration. Unify credential matching across ordinary password prompts, preserving legacy migration and replacement after rejection.
