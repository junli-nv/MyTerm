# MyTerm 1.4.7

- 修复端口转发配置文字截断，监听与目标端口标签改为输入框上方显示。
- SSH 配置改为可调整大小的独立窗口，支持最大化/还原与系统全屏。
- 长配置区域显示固定滚动栏，底部取消、保存及保存并连接按钮保持可见。
- 加入多级跳板机、代理、三种端口转发同时展开时的中英文、小/大窗口及最大化回归检查。
