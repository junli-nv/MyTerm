# MyTerm 3.4.6

## 简体中文

- SSH 密码管理新增“复制密码”，无需显示即可复制最新保存值，并显示结果。
- 显示密码改用原生只读文本框，支持稳定选择与复制；列表操作按钮独立响应，保持失焦隐藏。

## English

- Add Copy Password to SSH password management, copying the latest saved value without revealing it and reporting the result.
- Use a native selectable read-only field for revealed passwords and independent list buttons; preserve focus-loss hiding.
