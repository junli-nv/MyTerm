# 发布说明归档 / Release notes archive

此目录的 `RELEASE-NOTES-<版本>.md` 保留各版本发布时的记录。旧安装包清理不删除这些说明或源代码标签。这里的功能、默认值、测试结果与限制属于对应历史版本，不能替代当前使用说明。

The `RELEASE-NOTES-<version>.md` files preserve the records written for each release. Removing old installers does not remove these records or source tags. Features, defaults, test results and limitations describe the historical release, not necessarily the current application.

- 当前指南 / Current guide: [中文](../README.md) · [English](../README.en.md)
- Codex 接入 / Codex integration: [中文](../docs/CODEX-INTEGRATION.md) · [English](../docs/CODEX-INTEGRATION.en.md)
- 完整原始历史 / Full original history: [CHANGELOG.md](../CHANGELOG.md)
- 英文历史摘要 / English history summaries: [CHANGELOG.en.md](../CHANGELOG.en.md)

原始说明包含中文和中英双语条目；英文历史入口提供每个版本的摘要及原文链接，并非完整逐句翻译。新增版本说明应同时提供中文和英文，或同步维护对应的语言文件。第三方文档与许可证保留上游原文。

Original records contain Chinese and bilingual entries. The English history provides a summary and source link for every version, rather than a full translation. New release notes should include both languages or maintain matching language files. Third-party documentation and licenses retain their upstream text.
