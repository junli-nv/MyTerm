# MyTerm 3.1.8

## 简体中文

- 标签点击、右键菜单及拖拽由同一个原生控件处理，移除应用级右键监听和混合手势处理。
- 点击区域覆盖整条标签高度，包括上下留白；关闭按钮保留独立操作。
- 回归检查覆盖完整按下/松开、菜单持续显示、边缘命中、关闭和原生拖拽载荷；真实触摸板仍需人工验证。
- 包含 3.1.7 的多 Codex 独立授权和文档整理。

## English

- One native tab control handles selection, context menus and dragging, replacing the app-wide mouse monitor and mixed gesture handlers.
- The hit area spans the full tab-strip height, including padding; the close button retains its own action.
- Regressions cover full press/release gestures, menu persistence, edge hit areas, closing and native drag payloads. Physical trackpad input still requires manual validation.
- Includes 3.1.7's independent multi-Codex authorization and documentation updates.
