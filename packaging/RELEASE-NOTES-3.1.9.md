# MyTerm 3.1.9

## 简体中文

- 修复触摸板双指按下被传递为左键类型、右键按钮编号时标签菜单不响应的问题；同一次按下的重复事件不再重复弹出菜单。保留单击切换与终端输入焦点、标签拖拽和双击标题栏空白处最大化。
- 增加混合类型/按钮编号、重复事件去重及切换后键盘焦点回归检查。
- 包含 3.1.7–3.1.8 的多 Codex 独立授权、原生标签控件与文档更新。

## English

- Fix tab context menus for trackpad presses delivered as primary-typed events with the secondary button number. Duplicate events from one press do not reopen the menu. Preserve single-click selection and terminal focus, tab dragging, and double-clicking blank title-bar space to maximize.
- Add regressions for mixed event type/button number, duplicate suppression and keyboard focus after switching tabs.
- Includes independent multi-Codex authorization, native tab controls and documentation updates from 3.1.7–3.1.8.
