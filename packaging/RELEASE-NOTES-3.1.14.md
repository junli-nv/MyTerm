# MyTerm 3.1.14

## 简体中文

SSH 编辑器先选择认证方式：密码与私钥输入互斥显示；自动模式沿用已有配置。切换模式保留原有凭据，密码模式不再传递私钥文件。

包含本地版本 3.1.13 的可选 SSH 密码预填：密码保存到应用加密凭据库，留空保留已有密码；旧密码被拒绝后，可输入新密码并在登录成功后记住。

## English

Choose SSH authentication before entering credentials. Password and private-key inputs are mutually exclusive; Automatic uses existing configuration. Switching modes preserves credentials, and password mode no longer passes a private-key file.

Includes optional SSH password entry from local version 3.1.13: passwords use the app’s encrypted credential store, blank retains the existing password, and rejected passwords can be replaced and remembered after successful login.
