# MyTerm 3.3.7

## 简体中文

- 分屏快捷键和普通分屏菜单直接拆分当前焦点区域：本地 Bash 新开同目录终端，SSH 复用连接配置建立独立连接。
- 保留“上下/左右分屏并选择会话…”入口；Codex 区域仍显式选择会话，不隐式复制 AI 任务。
- 新分屏只平分当前区域，保留其他分屏的布局和比例。

## English

- Split shortcuts and standard split menus directly split the focused pane: local Bash opens a terminal in the same directory; SSH reuses the connection configuration for an independent connection.
- Explicit choose-session split actions remain available; Codex panes retain the chooser rather than implicitly duplicating AI tasks.
- New splits halve only the focused pane and preserve other panes and divider proportions.
