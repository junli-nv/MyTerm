# MyTerm 3.0.2

## 简体中文

切换界面语言后，编辑和窗口菜单中的系统项目（自动填充、居中、窗口排列等）立即同步，无需重启。保留系统操作、快捷键和窗口名称。

## English

System commands in Edit and Window (including AutoFill, Center and window arrangement) now follow language changes immediately, without restarting. Native actions, shortcuts and window names are preserved.
