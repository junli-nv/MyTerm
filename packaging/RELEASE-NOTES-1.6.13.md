## MyTerm 1.6.13（Build 138）

- MCP 计划、命令提交及状态查询返回当前 UI 授权模式，明确本会话始终允许可替代旧启动提示中的默认逐条确认；保留用户独立提出的限制。

- SSH 标签右键菜单增加“复制会话 ID（Codex）”，复制当前运行标签的 UUID，可直接提供给 Codex 的 MyTerm MCP 工具。
- 会话 ID 区分同一服务器的不同连接；关闭标签后新建连接会产生新的 ID。复制 ID 不改变共享或执行授权。
- 内置 Codex 启动时已自动携带所选 SSH 会话 ID，无需手动复制。
