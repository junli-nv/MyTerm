# MyTerm 3.1.5

## 简体中文

- 全屏终端双指滚动默认加速 4 倍，可切换标准或 Page Up / Page Down 按页模式。
- 按页模式限速并忽略惯性，适合 tmux 复制模式；中英文设置与偏好备份同步更新。

## English

- Full-screen trackpad scrolling defaults to 4× speed, with Standard and Page Up / Page Down options.
- Page mode is rate-limited and ignores momentum, useful in tmux copy mode; bilingual settings and preference backups are updated.
