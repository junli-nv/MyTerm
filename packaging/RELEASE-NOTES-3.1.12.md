# MyTerm 3.1.12

## 简体中文

Codex 默认路径改为 `/opt/homebrew/bin/codex`，保留已有自定义路径。修复 SSH 命令审批及执行控制按钮切换语言后仍显示中文的问题；关于窗口链接改为 MyTerm 项目主页。

包含 3.1.11 的端口转发删除入口改进。

## English

Default the Codex executable to `/opt/homebrew/bin/codex`, preserving saved custom paths. Fix stale Chinese labels in SSH approval/execution controls after language changes. Link the About window to the MyTerm repository.

Includes the forwarding-rule removal improvements from 3.1.11.
