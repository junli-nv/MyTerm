# MyTerm 3.1.3

## 简体中文

- 本地 Codex 可直接启动，无需 Bash/SSH 标签或 MyTerm MCP。
- 默认使用用户主目录，可选择项目目录，复用 Codex 登录和 HTTP/SOCKS5 代理。
- 本地执行使用 Codex 自身沙盒与审批；SSH 接入及授权保持独立。

## English

- Launch local Codex directly, without a Bash/SSH tab or MyTerm MCP.
- Start in the home directory or choose a project, reusing Codex login and HTTP/SOCKS5 proxy settings.
- Local execution uses Codex native sandbox and approvals; SSH access and authorization stay independent.
