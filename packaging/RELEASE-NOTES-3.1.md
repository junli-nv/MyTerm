# MyTerm 3.1

## 简体中文

- 设置与 Codex 接入改为左侧纵向分类，窗口可缩放，内容可滚动。
- 增加夜空、北境、柔雾与暖奶油配色及预设色板预览，保留原有主题和颜色编辑功能。
- 简化字体设置，移除自定义字体名称和已安装字体搜索入口，保留字体下拉选择与字号调整。

## English

- Vertical sidebars for settings and Codex Integration with a resizable window and scrolling content.
- Add Night Sky, Northern Night, Soft Mist and Warm Cream palettes with visual preset previews; preserve existing themes and color editing.
- Simplify font settings: remove custom-name and installed-font search controls, retaining the font dropdown and size controls.
