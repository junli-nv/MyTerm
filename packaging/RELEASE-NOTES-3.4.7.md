# MyTerm 3.4.7

## 简体中文

- 启用右键直接粘贴时，允许从其他应用切回后的第一次右键直接粘贴，避免只激活窗口而需要再次点击。
- 增加未激活窗口的首次点击策略、单次粘贴、中文/多行、括号粘贴及终端焦点回归检查。实际 VS Code 切换与自定义 tmux 配置仍需人工确认。

## English

- When direct right-click paste is enabled, accept the first paste click from another app instead of requiring a second click after window activation.
- Add inactive-window first-click policy, single-paste, Unicode/multiline, bracketed-paste and terminal-focus regressions. Physical VS Code switching and custom tmux configurations still need manual confirmation.
