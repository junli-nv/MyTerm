需要 macOS 14+、Swift 6.0+，SwiftTerm 源码随仓库提供，版本和渲染扩展说明见 `vendor/SwiftTerm/MYTERM-PATCH.md`。

```bash

open dist/MyTerm.app
```

## SSH 连接

添加或编辑服务器时可配置：

- **认证方式**：自动、密码、密钥。自动沿用 OpenSSH 的认证选择；密码模式启用密码 / 键盘交互并禁用公钥；密钥模式只使用公钥认证，可指定私钥文件，也可使用 SSH agent 或 SSH 配置中的密钥。
- 密码在 SSH 认证窗口输入，默认勾选“登录成功后记住密码”，验证成功后加密保存到应用自己的 SQLite 数据库，下次自动使用；旧密码被拒绝后提示更新。密码不进入终端按键流、历史、服务器 JSON、进程参数或环境变量。密钥口令、验证码和主机指纹确认保持手动交互，不自动保存。
- 记住的密码按连接定义与 OpenSSH 的主机 / 用户提示隔离；修改连接定义后可能需要重新输入。设置中的 **SSH 密码** 页面可清除 MyTerm 已保存的密码。自定义、无法明确识别的认证提示只用于本次认证，不保存。应用不调用系统钥匙串；旧版本的钥匙串密码不会自动导入或删除，首次连接需重新输入。
- **SSH 压缩**默认开启，可为单个服务器关闭。
- **跳板机**：填写 `user@B:22` 或 SSH Host 别名；多个跳板用逗号分隔。目标 A 填在主机字段，跳板 B 填在跳板机字段。跳板自己的用户名、密钥等可写入 `~/.ssh/config`。
- **网络代理**：HTTP CONNECT 或 SOCKS5，填写地址和端口。当前支持无需代理认证的服务；可与跳板组合，代理应用到第一跳。
- **端口转发**：本地 `-L`、远程 `-R`、动态 SOCKS `-D`，支持多条规则，默认监听 `127.0.0.1`。转发跟随 SSH 连接生命周期；监听失败时连接报错退出。远程转发的监听范围仍受服务端配置约束。

点击侧栏“导入 SSH 配置”，或按 `⌘⇧I`，勾选需要的 Host 别名。导入器支持普通 Include、文件通配符及递归防循环；跳过 Host 通配模式和重复别名。导入阶段不执行 Match exec，Include 中的环境变量和百分号 token 暂不展开。保存的是别名，连接时由 OpenSSH 读取实际配置，因此后续修改 SSH 配置仍生效。

## SFTP 与断点续传

SFTP 面板默认收起。SSH 登录成功后，打开底部状态栏的 **SFTP 文件** 开关，再点击面板中的 **连接**。SFTP 复用当前认证后的 SSH 连接，不重复询问密码。支持目录浏览、路径跳转、单文件上传、下载、进度和取消，文件名使用 UTF-8。

中断或取消后，重新连接 SFTP，再选择**相同源文件和目标路径**即可续传。传输使用 `.myterm-part` 临时文件及 JSON 元数据，完成后才提交目标文件。上传验证源文件 SHA-256，下载验证连接标识、远端路径、大小和修改时间；下载不提供远端整文件哈希校验。不要在传输或续传期间修改源文件。

上传遇到已有完整文件时要求更换名称；下载覆盖由保存对话框确认。当前不支持递归文件夹传输。

## Zmodem

本机需安装 `lrzsz`，远端也需提供 `rz` / `sz`：

```bash
brew install lrzsz
```

在 SSH 终端运行 `sz 文件名`，MyTerm 会询问本地接收目录；运行 `rz`，MyTerm 会询问要发送的本地文件。协议数据不会显示成终端乱码，底部显示传输状态并提供取消按钮。接收保护已有文件，发送请求续传，是否接受由远端接收器决定。应用会查找 `/opt/homebrew/bin`、`/usr/local/bin` 和 `/usr/bin` 中的工具，不将 lrzsz 打包进应用。

也可把 Finder 中的一个或多个普通文件直接拖到**已登录的 SSH 终端**：应用清除当前未提交的命令行、执行 `rz`，收到握手后自动上传，不再打开选文件对话框。目标目录是远端 shell 当前目录；上传过程中可取消。请先停留在普通 SSH shell 提示符；ZMODEM 不适用于 tmux；启用下述 trzsz 后，自动模式在备用屏幕中改用 trzsz。不要在 vim 等编辑器中拖拽。远端未安装 `rz` 或 15 秒内没有握手时，会显示提示。

## 会话和终端

- 本地交互式 Bash 登录 shell，遵循 `~/.profile` 等 Bash 启动文件规则。
- 多标签保持各自进程和终端内容；关闭标签结束对应 shell / SSH 进程。
- `⌘T` 新建本地终端，`⌘N` 添加服务器，`⌘W` 关闭标签。
- 点击标签栏左端的侧栏按钮，或按 `⌃⌘S` 显示 / 隐藏左侧栏；隐藏状态在重启后保留，SSH 和本地终端均可使用腾出的空间。
- `⌘⇧S` 保存当前会话，侧栏会话菜单可恢复或删除。保存标签顺序、连接定义、选中标签及本地目录记录，最多 100 个标签；退出时保存“上次退出时的会话”。恢复会追加标签，SSH 标签首次选中时连接。
- 会话恢复会重新建立连接，不会将历史文本写回活动终端，也不恢复远端进程；已记住的密码由应用本地凭据库读取，历史文本在单独的历史窗口查看。需要远端进程持续运行可使用 tmux。本地目录随 OSC 7 更新，未配置 shell 目录上报时保留初始目录。
- 默认选中文字自动复制、右键直接粘贴。在 **MyTerm → 设置…（⌘,）** 独立开关，立即生效并持久保存。**Shift + 右键** 始终显示菜单，`⌘C` / `⌘V` 可用。

服务器和会话保存在 `~/Library/Application Support/MyTerm/servers.json` 与 `sessions.json`。旧版服务器文件兼容读取；配置损坏时显示错误并保留原文件。

## 历史文本与主题

**文件 → 会话历史…（⌘⇧H）** 或侧栏“会话历史与导出…”可查看已存档的本地 / SSH 会话，按名称筛选、在文本中用 `⌘F` 查找、导出或删除。**文件 → 导出当前会话文本…（⌘⇧E）** 将当前标签内容保存为 UTF-8 `.txt`，去除 ANSI 控制序列和宽字符占位符。

每个标签保留最近 50,000 行回滚及当前屏幕，每 30 秒、关闭标签和退出应用时保存到 `~/Library/Application Support/MyTerm/History/`，重启后仍可查看。历史是终端缓冲快照，不是无限日志或逐帧录像；已被清屏删除或超出回滚范围的内容无法补回。tmux / vim 等全屏程序会附上当前画面，其内部历史需在程序内查阅。删除仍打开的会话记录后，本次连接不再自动生成该记录。异常退出可能丢失最后 30 秒尚未保存的快照。

**MyTerm → 设置… → 主题与字体** 支持深色、浅色和 Solarized 预设，界面跟随系统 / 深色 / 浅色，等宽字体、9–36 pt 字号、文字 / 背景 / 光标 / 选区颜色及预览。设置立即应用到所有标签并持久保存；程序自己的 ANSI 配色由程序控制。

## tmux 与屏幕共享

新 PTY 使用 `xterm-256color`，清除启动应用时继承的 `TMUX`、`TMUX_PANE`、`LINES`、`COLUMNS` 等环境，避免误判嵌套会话或沿用旧尺寸。tmux 内部的 TERM 由 tmux 自己设置，应为 `screen` / `tmux` 系列；不要在 shell 启动文件中无条件覆盖它。参见 [tmux 官方 FAQ](https://github.com/tmux/tmux/wiki/FAQ)。

远端 shell 和 tmux 需要有效的 UTF-8 locale 才能正常处理中文输入；应用沿用 SSH 与远端环境设置，不修改服务器配置。回归测试使用独立 UTF-8 环境，已在本机 tmux 3.6a 下通过。

标签切换和布局变化会合并处理，并过滤临时零尺寸，避免向 SSH / tmux 上报无效行列数。尺寸以 AppKit 逻辑点计算，不按屏幕像素比例放大。

屏幕共享前勾选标签底部的 **锁定尺寸**：窗口缩放、侧栏布局变化时保持终端区域大小；可滚动查看被较小窗口遮住的部分。取消后恢复自动适配。手动改变字体仍会改变行列数；该开关不控制远端其他 tmux 客户端的尺寸策略。

可选的真实 SSH / tmux 窗口回归测试（本机需有 tmux 和 lrzsz）：

```bash
MYTERM_TMUX_CHECK=1 bash scripts/check-integration.sh
```

使用临时 SSH 服务和独立 tmux socket，不读取或改写用户 tmux 配置。检查中文和彩色输出、双窗格、尺寸同步、锁定尺寸和退出全屏。具体会议软件或 macOS 屏幕共享的实际采集链路仍需在相应环境验收。

独立密码集成测试使用 Paramiko 建立临时本地 SSH 服务，并用真实 OpenSSH、应用的 askpass 通道及独立测试 SQLite 凭据库验证首次保存、自动登录、密码轮换和再次自动登录；测试结束会删除测试凭据目录，不涉及真实账号密码：

## 自定义分组与会话管理

启动默认显示开始页面，不自动打开本地 Bash。可在开始页新建 SSH 会话、选择已保存的服务器连接，或手动打开本地终端（`⌘T`）。标签栏右侧 `+` 提供同样的选择，不再直接打开本地会话。

右键标签可选中、关闭、复制会话或更改标签名称；SSH 标签还可更改连接配置，断线时可重新连接。复制会话创建独立连接，本地会话沿用当前目录，不复制终端进程或历史。标签重命名仅影响当前标签。更改 SSH 配置不会中断当前连接，可在编辑窗口保存配置或“保存并连接”新建连接。点击标签栏空白区域的“新建会话…”或右侧 `+`，可选择本地、SSH、已保存服务器、已保存的多标签会话或导入配置；空白区域右键提供相同菜单。

在 **文件** 菜单或侧栏 **保存与恢复会话** 菜单选择 **导出会话配置… / 导入会话配置…**，使用 MyTerm 的版本化 JSON 文件备份、迁移服务器、分组和已保存的多标签会话。当前打开的标签须先“保存当前会话”再导出。密码、私钥文件和终端历史文本不包含在内；SSH 配置别名及密钥路径在目标 Mac 上需另行配置。

导入不会发起连接或替换当前标签。完全相同的记录跳过；相同编号但内容不同、分组名称重复或文件无效时取消整次导入并显示原因，不覆盖已有配置。文件上限 20 MB。

左侧 **SSH 服务器** 标题旁的文件夹加号用于新建分组。右键服务器选择 **移至分组**，可移入自定义分组或移回“未分组”。点击分组名称展开 / 折叠；分组右侧菜单可重命名或删除。删除分组后，其服务器回到“未分组”，连接定义保留。搜索框同时匹配分组名称、服务器名称、地址和用户名；搜索时会展开匹配项。

分组与折叠状态保存在 `~/Library/Application Support/MyTerm/groups.json`，与连接定义分开保存，因此分组调整不会改变 SSH 参数、已记住的密码或活动连接。旧版服务器自动显示在“未分组”。

- **服务器会话**：`⌘N` 或侧栏加号添加；右键服务器编辑或删除配置。删除配置不关闭已经打开的连接。
- **当前标签**：`⌘T` 新建本地会话，双击侧栏服务器新建 SSH 会话（单击不连接），也可右键选择“连接”；`⌘W` 或标签关闭按钮结束当前会话。
- **保存的多标签会话**：`⌘⇧S` 新建保存记录；“保存与恢复会话”菜单中可恢复、重命名、用当前标签配置更新，或删除记录。更新保留记录名称和编号，并替换标签配置、顺序及选中位置。


## 应用自管的密码存储

在 **设置 → 密码管理** 中，可为已保存密码设置名称、查看关联服务器/会话，并点击“查看密码”显示本地保存的密码。密码默认隐藏，离开页面或窗口失去焦点后自动隐藏；自定义名称随偏好设置备份保存，更新密码时保留。

密码使用系统自带 SQLite 管理，采用 CryptoKit 的 AES-256-GCM 加密和完整性校验；每次保存使用新的随机 nonce，并将账号标识绑定到密文。SQL 使用参数绑定。没有系统钥匙串读写，也没有新增加密算法实现。

存储目录：`~/Library/Application Support/MyTerm/Credentials/`。数据库为 `passwords.sqlite`，本地加密密钥为 `encryption.key`；目录权限为 `0700`，数据库和密钥为 `0600`。密钥缺失或不匹配时不会静默生成新密钥覆盖旧数据库。

为保留无主密码的自动登录，密钥由应用保存在本机。此方案避免数据库直接存放明文，但能同时读取数据库和密钥的进程仍可解密；它不是主密码保护的密码库。迁移或备份时须同时保存数据库和密钥。

**MyTerm → 设置… → 终端行为 → 禁用终端响铃** 控制本地 shell 和 SSH 的 BEL 响铃，默认禁用。修改立即作用于所有标签，并在重启后保留；取消勾选可恢复终端响铃。

在终端区域按住 **Ctrl**，触摸板双指上滑放大字体、下滑缩小字体。每步 **0.5 pt**，至少间隔 **150 ms**，忽略惯性滚动；字号限制为 **9–36 pt**，同步到主题设置并保存。未按 Ctrl 时保持普通滚动行为。

**设置 → 主题与字体** 默认列出全部已安装字体，支持搜索、“仅等宽”筛选，以及输入自定义字体名称并应用。通过 macOS 字体册安装新的字体后，点击“刷新”即可选择。未知字体不会覆盖当前设置；终端表格和 tmux 建议使用等宽字体。

本地 Bash 和 SSH 正常 `logout` / `exit` 后自动关闭对应标签，并按现有设置保存历史。SSH 异常断线保留标签与历史，聚焦终端后按 `R` 或 `r`，或点击状态栏“重新连接”，即可在原标签重连。

SSH / SFTP 默认启用 `ServerAliveInterval=30`、`ServerAliveCountMax=6` 和 `TCPKeepAlive=yes`，减少空闲连接被断开的情况。保活无法避免实际网络中断；需要在断线后继续运行远程程序时，可使用 tmux。

## 密码、密钥、编码与 OpenSSH 配置

**设置 → SSH 密码** 列出已保存记录，可更新单条密码、删除或清空。更新只改变本地密码，不修改服务器密码。新记录显示服务器及认证提示；旧版哈希记录显示编号。密码继续保存在应用自管的加密 SQLite 中，不使用系统钥匙串。

**设置 → SSH 密钥** 可导入私钥、查看附带的公钥和删除应用内副本。 密钥列表显示应用内显式引用该文件的服务器、保存会话、已打开标签及各级跳板机；路径匹配支持 `~` 和符号链接。删除被引用的密钥时会列出受影响会话并要求额外确认，取消任意一次确认均保留密钥。外部程序和 SSH 配置文件的隐式引用不在统计范围内。支持 ssh-keygen 生成的 OpenSSH 和 PEM 私钥（包括口令加密格式），原样保留字节；是否能认证还取决于系统 OpenSSH、服务器算法策略及硬件密钥设备。导入会复制到 `~/Library/Application Support/MyTerm/Keys`（目录 0700、私钥 0600），不删除原文件、不去除口令。同名 `.pub` 一并复制；在 SSH 编辑窗口通过“密钥库”选择，也可继续直接选择 `~/.ssh` 下的私钥。

**文件 → 导出 OpenSSH 配置…** 导出侧栏服务器配置，使用 `ssh -F /path/to/myterm_ssh_config Host别名`。支持认证选项、保活、压缩、密钥路径、跳板、代理和端口转发。保留对当前 `~/.ssh/config` 和系统配置的 Include 引用，所以原 SSH 别名及跳板定义仍有效；代理配置引用 MyTermProxy。迁移到另一台机器时需同时配置这些依赖和密钥路径。本导出不是包含所有依赖的独立备份，不覆盖原 `~/.ssh/config`。同主机别名的多条配置会提示冲突；JSON 备份仍可保留这些记录。

终端底部 **编码** 可选择 UTF-8、GB2312、GBK、GB18030、Big5、Shift-JIS、EUC-KR、ISO-8859-1，默认 UTF-8。切换对后续输入输出生效，不重新解释已有历史；复制会话和保存的多标签会话保留编码。无法表示或无效的字符使用替代字符。SFTP 和 ZMODEM 二进制数据不做字符转换。

## SCP 与下载续传

ZMODEM 上传、下载状态栏显示实时速率（B/s、KB/s、MB/s 自动换算），每 250 ms 更新，以最近约 2 秒的数据平滑计算；传输完成后显示平均速率。该速率统计 ZMODEM 数据流，包含协议开销及重传，不等于文件净写入速度。

SSH 文件面板增加 **使用 SCP（断点续传使用 SFTP）**。首次完整传输通过系统 `/usr/bin/scp`，复用当前已认证 SSH 连接；现代 OpenSSH scp 默认使用 SFTP 协议，不强制旧版 `-O` 协议。目录浏览、文件校验及最终重命名仍依赖 SFTP。SCP 阶段显示等待状态，SFTP 续传阶段显示字节进度。

下载中断或取消后，重新连接文件面板，选择**同一远端文件和同一本地保存路径**，再次“下载 / 续传”即可继续。不要删除旁边的 `.文件名.myterm-part` 和 `.json` 元数据。SCP 自身没有续传能力，已有非空临时文件会通过 SFTP 从已有偏移继续，不重新调用 SCP 覆盖临时文件。上传同理。远端大小、修改时间、连接身份等元数据不匹配时拒绝续传；上传还校验源文件 SHA-256。下载完成后才将临时文件替换为最终文件。

## 传输速度、语言与完整偏好备份

SFTP / SCP 文件面板显示上传、下载实时速度，约每 250 ms 更新并平滑处理，结束后显示平均速度。SFTP 根据传输字节计算，SCP 采样远端或本地临时文件大小；断点续传只计算本次新增的字节，不把此前完成的部分计入速度。

**设置 → 语言** 支持简体中文、English 和跟随系统。选择自动保存，立即应用到菜单、主要页面和设置，无需重启，不中断当前连接。远端终端内容、用户自定义名称及部分底层诊断保持原文。

**文件 → 导出偏好设置备份… / 恢复偏好设置备份…** 使用 `.mytermbackup` 加密文件，包含服务器、分组、保存的多标签会话、当前标签的配置快照、主题、语言、鼠标/响铃/侧栏偏好、已保存密码及应用密钥库。终端历史、外部 `~/.ssh/config`、外部私钥文件及已安装字体不打包；这些依赖在迁移时需另行准备。应用密钥路径会在恢复时适配当前用户目录。

备份使用口令派生密钥（PBKDF2-HMAC-SHA256，310,000 次迭代、随机盐），通过 AES-256-GCM 加密并校验完整性。忘记备份口令无法恢复。恢复先解密、验证，再确认替换当前配置并关闭连接；写入失败会尝试回滚，原历史保留。恢复后重启以应用全部偏好。原有 JSON 会话导出仍不包含密码或私钥。

## X11 转发

SSH 编辑窗口可选择关闭、普通转发（`-X`）或受信任转发（`-Y`）。**默认关闭**，包括未设置此字段的旧会话，即使原 SSH 配置打开转发也默认禁用；需在会话中显式开启。相关参数也随 OpenSSH 配置导出。

启用时需本机安装、运行 XQuartz，并由远端 sshd 允许 X11Forwarding；应用会从环境或 launchctl 获取 DISPLAY，缺失时提示启动 XQuartz。受信任模式仅用于可信服务器。此环境未安装 XQuartz，因此已验证参数生成与默认值，尚未验证远端图形窗口的实际显示。

## trzsz 文件传输（tmux）

SSH 连接默认启用内置 trzsz-go 1.2.0 客户端，无需在 Mac 另装客户端。远端需安装 [trzsz-go](https://github.com/trzsz/trzsz-go) 的 `trz` / `tsz` 并加入 PATH。在远端 shell（包括 tmux 窗格）执行 `trz` 选择本地文件上传，执行 `tsz 文件名` 选择本地目录下载；`trz -d` / `tsz -d 目录` 支持目录。终端显示进度与速度，Ctrl+C 取消。

编辑 SSH 会话可关闭 trzsz，或指定拖拽上传协议。自动模式按备用屏幕判断：普通 shell 使用已有 ZMODEM，tmux 等全屏终端使用 trzsz；也可固定使用 trzsz。请停留在 shell 提示符再拖拽，不能以此区分 tmux 和 vim。设置保存后重新打开连接生效。原有连接不被自动中断。

通过应用配置的 ProxyJump 多级跳转可保持原设置。如果先登录中间服务器、进入该机 tmux，再手工 SSH 到下一台服务器，需在中间机安装 trzsz 客户端并使用 `trzsz --relay ssh 目标`（见上游中继说明）。

客户端会沿用用户已有 `~/.trzsz.conf` 的选择目录等设置。协议传输在终端字符解码前由独立客户端处理。`scripts/trzsz-check.py` 使用隔离 PTY/tmux 与模拟文件选择器验证实际文件内容；`MYTERM_TRZSZ_CHECK=1 bash scripts/check-integration.sh` 验证 SSH 包装后的代理、跳转、端口转发与 SFTP。

窗口顶部将标题区域与标签栏合并为单行，保留系统红黄绿按钮。底部状态栏在新会话中默认隐藏；点击标签栏左侧的底栏图标展开 SFTP、编码及尺寸锁定选项。断线状态和传输状态仍可显示。

使用 Ctrl+Tab 切换到下一个标签页，Ctrl+Shift+Tab 切换到上一个；首尾循环，可在“窗口”菜单中查看。快捷键在主终端窗口生效，不发送到远端 shell/tmux。

发布流程会对 Debug 和实际 Release 应用执行相同的窗口鼠标交互检查，验证侧栏、底栏、SFTP 面板展开/收起、标签切换后的状态，以及双击最大化/还原；任一失败都会阻止生成 ZIP。SSH 标签栏提供独立 SFTP 开关，无需先展开底栏。

### 输出着色与终端留白

**设置 → 输出着色** 默认对 SSH 输出中的 Error、fail 等词标红，up、active、ok 等词标绿，warning 等词标黄。可添加或删除规则、自定义关键词和颜色、调整优先级，并选择整词匹配和区分大小写。多个关键词用逗号分隔，按普通文本匹配。设置立即生效，随偏好设置备份导入导出。

默认保留远端 ANSI 颜色，仅对 SSH 普通屏幕生效；本地终端及 tmux/vim 等全屏程序可以单独开启。着色只作用于显示，复制、历史导出及传输的数据保持原样。终端左右各保留 8 点空白，自动适配的列数按实际可用宽度计算。

### 安装一致性检查

`bash scripts/create-dmg.sh` 挂载生成的 DMG，逐项核对包内应用与 Release 构建的文件、权限及符号链接，复制到独立目录后执行相同的窗口及着色测试。`bash scripts/install-release.sh` 从该 DMG 安装到 `/Applications/MyTerm.app`，再次核对文件、签名并运行窗口测试，通过后打开安装版；安装验证失败时恢复原应用。该脚本同时将 `dist/MyTerm.app` 同步为相同的已验证产物，不另行构建。

### 灵活配色与透明背景

在 **设置 → 主题与字体** 中分别编辑普通/明亮 ANSI 16 色，以及文字、背景、光标、光标文字、选区背景和选区文字。颜色选择器支持系统调色，旁边的 HEX 框支持输入 `#RRGGBB` 后回车应用。提供深色、浅色、Solarized、午夜蓝、柔和纸白五个预设及真实终端预览。

“背景不透明度”从 0%（透明）到 100%（不透明），默认 100%；仅影响默认背景和左右留白，不会降低文字、光标、选区或程序指定背景色的透明度。预设切换保留字体、字号和透明度。完整设置随偏好设置备份保存。

导入/导出 `.itermcolors` 支持基础六项颜色和 ANSI 16 色，保留字体、字号、界面外观和透明度；缺失的颜色保持当前值。支持 sRGB、Calibrated 和 P3 输入，导出 sRGB。iTerm2 特有的光标引导线、徽标、明暗双方案等扩展不导入。ANSI 调色板不改写程序的 RGB 真彩色；关键词规则仍在“输出着色”中设置。

MyTerm 的交互式 SSH 使用 `-e none` 禁用外层客户端转义键处理，让 `~.` 等按键传给远端 ipmitool 等控制台程序。退出 SSH 可在远端 shell 输入 `exit`，或关闭标签页。

会话日志默认关闭，可在「设置 → 终端行为」显式开启。可配置回滚/保存行数（默认 50,000 行）、单个历史文件大小（默认 20 MiB）和历史总容量（默认 500 MiB）。大小包括 JSON 元数据，超限保留最新文本，总容量超限清理最久未更新记录。手动导出不受自动日志开关影响。历史窗口可清理 30 天前或全部记录。
日志使用 gzip 快速压缩（可关闭），压缩/解压及磁盘操作在后台执行；文件与容量上限按实际压缩后大小计算。

日志保存开关是全局默认。SSH 配置及当前标签的右键菜单可分别选择「跟随全局设置」「始终保存日志」「不保存日志」。当前标签的选择即时生效，复制及保存/恢复多标签会话时保留；SSH 编辑中的选择随服务器配置保存，用于新连接。压缩、行数、单文件和总容量继续遵守全局限制。

SSH 配置使用独立可缩放窗口，支持最大化/还原与全屏。长配置区域显示固定滚动栏，底部保存操作保持可见；端口转发标签位于输入框上方，避免窄窗口截断。

复制默认合并终端记录的自动折行，保留硬换行；真实 LF 和行尾清除会更新旧折行关系，避免重绘后的短行被合并。字体缩放重新排版后仍按逻辑行复制。需要保留视觉排版时可用 Shift+右键 →「复制（保留屏幕换行）」。

注意：全屏程序若用光标定位逐行重画、未传递自动折行关系，终端无法从屏幕可靠区分原文件的硬换行与折行；此时仍可能按屏幕分行复制。

首次双击选择空白分隔的文本，保留路径、标点和自动折行；在选中文本上再次双击扩展为完整逻辑行，遇到真实换行停止。启用远端鼠标报告时，按住 Shift 双击可在本地选中。
