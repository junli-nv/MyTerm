# 测试与维护

简体中文 · [English](TESTING.en.md) · [README](../README.md)

Codex 执行配置回归覆盖命令字节数上下界、设置序列化与备份验证、较大请求的嵌套 JSON 传输、超过 1 MiB 的输出分页、不完整原因、审批模式与续期隔离，并检查中英文控制栏和可滚动配置表单。

## 完整回归入口

在仓库根目录运行。需要 macOS 图形会话、Swift、系统 OpenSSH/SFTP、Codex CLI、tmux、lrzsz，以及安装了 `scripts/requirements-password-test.txt` 的独立 Python 虚拟环境。缺少依赖会失败，不会静默跳过。

```bash
bash scripts/check.sh
bash scripts/build-app.sh debug /tmp/myterm-check/Debug/MyTerm.app
python3 scripts/check-all.py /tmp/myterm-check/Debug/MyTerm.app --configuration debug
```

`--password-python` 可指定密码测试的虚拟环境解释器，默认 `.test-venv/bin/python`。`--logs` 指定日志目录；默认在系统临时目录创建独立目录。逐项日志和 `summary.json` 保留退出码与耗时。失败立即停止，修复后重新运行失败项及受影响测试。图形检查串行执行，以免互相抢占窗口焦点；测试期间避免操作测试窗口。

Release 检查必须使用相应构建的核心测试程序和指定应用：

```bash
swift build --build-system native -c release --product MyTermChecks
bash scripts/build-app.sh release /tmp/myterm-check/Release/MyTerm.app
python3 scripts/check-all.py /tmp/myterm-check/Release/MyTerm.app --configuration release
```

安装并启动 XQuartz 后，加 `--x11` 可验证真实 X11 窗口（关闭、不可信及可信转发和连接退出清理）；未启用时 `summary.json` 会明确记录。也可单独运行 `python3 scripts/x11-check.py`，通过 `MYTERM_TEST_CONFIGURATION` 指定 Debug/Release。

也可将应用参数换为 `/Applications/MyTerm.app` 或从 DMG 复制的应用。此入口不会构建、安装、发布或修改 Release。不能用 `swift test` 替代：本项目核心回归由可执行目标 `MyTermChecks` 驱动。

分屏回归覆盖上下/左右嵌套布局、真实终端鼠标焦点、移动/移出、关闭后补位、会话布局恢复和自定义快捷键持久化；核心检查覆盖布局折叠、无效引用和快捷键冲突。分隔线比例不持久化。 回归还验证首次等分、动态嵌套不改变其他区域、手动调整后再分屏及关闭子区域保持父级比例。

广播回归使用独立 Bash PTY 和文件结果验证两个目标实际执行、未选中目标隔离、就绪确认、输入上限、Codex / 断线 / 旧连接拒绝及切换标签和布局清理。不会假设终端输入提交等于远端命令成功。

更新回归覆盖版本比较、架构选择、下载地址限制、SHA-256 和大小校验，以及模拟 GitHub HTTP 成功、限流和错误响应。`scripts/update-installer-check.py` 使用临时签名应用验证替换、版本/签名错误保留旧应用及启动失败回退；不操作用户安装的 MyTerm。

## 专项回归

跳板凭据回归覆盖配置时保存、留空保留、共享路径复用、失效更新、旧记录和名称迁移、歧义提示隔离、复制多级路径及密码关联显示。

触摸板回归覆盖真实滚动事件的按页键编码、快速模式、多次滑动累积、限速、反向、惯性忽略，以及普通 Shell 和鼠标滚轮隔离。

键盘连发回归检查应用级重音菜单策略、英文输入源下普通/全屏终端的 h/j/k/l/a 重复按键事件，以及中文预编辑与提交；测试后恢复原输入源。合成重复事件不能替代物理键盘长按测试，长按阈值和系统重复速度仍需人工验证。

标签菜单回归通过 NSWindow 原生事件路径验证完整按下/松开：单击选中后右键、Control+单击、留白和边缘命中、松开后菜单保持显示、关闭按钮及正确操作目标。原生拖拽载荷检查覆盖排序和无效载荷；另覆盖左键类型/右键按钮编号的触摸板事件、同次按下去重与切换后的键盘焦点；重命名检查使用实际菜单与弹窗，验证标题/宽度立即更新、重复修改、取消和切换/排序后保持名称；右键检查还覆盖未选中标签的自动选择。物理触摸板操作仍需人工确认。

端口转发编辑检查覆盖删除中间规则、保留其他规则、重复删除已不存在的 ID、清空后保存/重新加载以及重新添加。

Codex 内联审批检查在同一窗口反复切换中英文，并识别英文状态下实际按钮截图中的文字；默认路径与自定义路径序列化也有核心检查。

Codex 回归同时验证同一 SSH 上两个客户端的独立授权、额度、审批和输出分页，以及命令排队、独立到期、续期和关闭清理；通过真实 stdio 适配器验证环境中的关联身份不会被工具参数覆盖。

终端诊断回归验证默认关闭、15 分钟到期、环形容量、并发记录和清除，以及 ZIP 解包内容一致性。终端输入检查覆盖选中后恢复输入的输出跟随、组合输入结束后切换键盘协议，以及普通英文 Return 在正常/备用屏幕及多种键盘协议中的首次按下。程序化事件不替代真实设备和真实 Codex 长时间交互验证。

## 覆盖边界

这些是功能回归，不是 100% 行/分支覆盖率，也不是所有功能组合的穷举证明。测试通过不代表不存在缺陷。

- X11 窗口测试需要 XQuartz，使用本机 SSH 转发和 xmessage；不代表所有远端图形应用或 GPU 加速均已验证。
- Codex 代理测试不调用真实模型、不验证付费账号/额度或模型建议质量；登录衔接采用模拟服务，不替代实际账号登录。
- Finder 文件承诺和面板手势有程序化检查，真实 Finder 拖放、设备输入法、屏幕分享及长时间使用仍需人工验收。
- 本机环回网络不代表公网高延迟、丢包、各种远端 SSH/SFTP 实现或硬件密钥均已验证。
- Apple Silicon 本机通过不等于 Intel 和最低 macOS 版本实机通过；短时进程回收检查不等于长期内存无泄漏证明。

## 可维护性约束

保持协议/持久化在 `MyTermCore`，窗口和交互在 `MyTerm`；手势与会话排序/分组修改分离。提取有明确职责的模块，不为缩短文件盲目重构。计时器与子进程要有关闭路径，后台结果要核对当前连接身份，分页与递归要有上限。缺陷优先加入可复现检查，再验证修复。

`MyTermApp`、`CodexBridge` 仍承担较多界面编排职责，后续新增行为应优先放入专注模块；拆分时保留现有回归入口。第三方 SwiftTerm 修改应记录于 `vendor/SwiftTerm/MYTERM-PATCH.md`，不要直接改动上游许可证。

Codex 启动页检查在中英文、640×480 与 800×700 尺寸下展开全部设置，验证取消／启动按钮位于滚动区域外且完整可见。

恢复回归覆盖原生历史选择器参数、新 SSH UUID 绑定、拒绝旧 UUID、授权与关联清理；控制栏检查覆盖宽窗口铺满及窄窗口滚动。`scripts/codex-resume-check.py /path/to/MyTerm.app` 使用真实 Codex CLI、隔离配置与合成对话，验证旧对话显示及新 MCP 关联初始化，不读取私人对话、不调用模型。发布打包会运行此检查；它不替代真实账号及模型行为测试。

SSH 断线状态栏检查在中英文下调整到宽窗口及窄分屏宽度，验证内容铺满或可横向滚动。

OpenSSH 导出检查使用系统 `ssh -G` 验证同主机不同用户/端口的会话参数独立，覆盖别名稳定性、已有主机名碰撞和重复输入。

公共跳板回归覆盖旧文件原始备份、定义去重、路径和认证差异隔离、更新传播、独立副本、悬空引用、冲突拒绝、归档和重载，以及迁移前后密码索引一致。编辑器回归核对密码显示／隐藏时文本不丢失、默认遮罩和保存的 JSON 不含密码。

SSH 配置检查回归覆盖仍被跳板引用的已删除节点、当前与快照导出范围、已保存／未保存／未知凭据、显式密钥存在性、未关联密码，以及异步加载和中英文小窗口滚动。检查不会尝试真实登录或验证密码正确性。

跳板机管理回归覆盖独立保存、引用保护、编辑传播、删除、双语小窗口、会话备份兼容；`scripts/jump-probe-check.py` 使用临时密钥和本机隔离 sshd 验证直连、多级路径、错误密钥及取消，不连接用户服务器。

`scripts/jump-password-probe-check.py` 使用仅支持密码认证、拒绝所有远端通道的隔离 SSH 服务，验证跳板测试复用密码、拒绝错误密码、不请求 Shell/exec 及连接清理。发布 GUI 检查会运行此项，默认使用 `.test-venv/bin/python`（安装 `scripts/requirements-password-test.txt`），可通过 `MYTERM_PASSWORD_TEST_PYTHON` 指定解释器。此项模拟受限服务器能力，不代表已在真实 Windows 主机上完成验证。

- `scripts/codex-cluster-check.py .build/release/MyTermChecks`：隔离 CODEX_HOME、本地假模型，真实 Codex 创建/命名/改名/持久化、目录隔离和原生 UUID 恢复；不调用模型。

集群刷新回归还覆盖默认分组改名后保留 ID 和目录、失败后记录保留、重试更新标题但不改变最后打开日期、初始/加载状态和取消。真实 CLI 的 `thread not loaded` 保持“无法验证”，不推断已删除；缺失状态只接受已识别的明确协议错误。

MCP 诊断管道回归：`python scripts/mcp-diagnostics-check.py /path/to/MyTerm.app`，使用隔离临时文件，覆盖握手、工具发现、EOF、错误输入、大小上限、关闭输出管道及隐私边界，不调用 SSH 工具。打包、DMG 和安装检查都会运行。

诊断摘要回归覆盖中英文说明、未检查及无事件状态、未知原因不回显原文、正常 EOF、事件丢失、多个辅助进程与成功主动检查并存时的故障解释，以及实际 ZIP 中两种摘要与原始元数据的一致性。
